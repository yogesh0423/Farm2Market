# 🌾 Farm2Market – Agricultural Marketplace Platform

> A full-stack agricultural marketplace platform designed to connect farmers directly with buyers, enabling product listing, discovery, order management, communication, and market insights through a centralized digital platform.

---

## 📖 Overview

Farm2Market is a full-stack web application developed to simplify the process of connecting farmers with potential buyers.

The platform provides farmers with a digital marketplace where they can list their agricultural products, manage inventory and pricing, and handle incoming orders. Buyers can browse available products, view product details, place orders, and track their order status.

The project aims to reduce dependency on traditional intermediaries while providing a structured digital platform for agricultural product discovery, transactions, and market information.

# ✨ Features

### 👨‍🌾 Farmer Module

- Farmer registration and login
- Farmer dashboard
- Create agricultural product listings
- Update product information
- Delete product listings
- Manage product quantity and pricing
- View incoming orders
- Update order status

### 🛒 Buyer Module

- Buyer registration and login
- Buyer dashboard
- Browse agricultural products
- Search and view products
- View product details
- Place orders
- Track order status

### 📦 Order Management

- Create and manage orders
- Order quantity management
- Order status tracking
- Farmer-side order management
- Buyer-side order tracking
- Order history

### 💬 Communication

- Buyer–farmer communication
- Order-related discussions
- Centralized communication workflow

### 📊 Market Insights

- Agricultural product pricing
- Price history
- Market trends
- Basic analytics and visualization

### 🔐 Authentication & Security

- User registration
- User login
- JWT authentication
- Role-based authorization
- Protected API endpoints
- Password hashing
